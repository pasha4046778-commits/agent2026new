# EU web studios / production agencies shortlist

Compiled a pragmatic shortlist of 52 notable EU-based web studios, product/web agencies, and e-commerce specialists.

## Notes
- Focused on web studios, web production companies, product/web shops, and e-commerce specialists.
- Excluded broad full-cycle digital agencies where possible, though a few high-signal exceptions remain (for example Dept, Infinum) because of strong web relevance.
- Data quality is mixed: the first 8 entries were directly verified from site content in this run; the rest are pragmatic market-known additions with lighter verification due web-search quota limits.
