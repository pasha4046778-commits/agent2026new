# Аудит DIKIDI.ru — раздел Business, онлайн-запись

Дата: 2026-07-29. Запрос Павла в топике Dev-Разработка. Источники: dikidi.ru/ru/promo/business, профиль компании в каталоге, база знаний support.dikidi.net.

## Общее

- Сервис онлайн-записи + CRM для сферы услуг, работает с 2014, включён в реестр российского ПО.
- Заявляют: 120 000+ компаний, 95 стран, 15+ млн записей в месяц.
- Два продукта: DIKIDI Online (клиентское приложение + каталог-маркетплейс) и DIKIDI Business (журнал/CRM для бизнеса, iOS/Android/web).
- `dikidi.ru/business` — сразу экран входа (Telegram / VK ID / Яндекс ID / телефон); весь маркетинг на `/ru/promo/business`.

## Каналы онлайн-записи (заявлено 10 способов)

1. Приложение DIKIDI Online (каталог, авто-публикация профиля компании)
2. Прямая ссылка на форму записи
3. Сайт dikidi.net
4. Виджет ВКонтакте
5. Виджет на свой сайт
6. Брендовое приложение компании (делают под фирменный стиль, платно)
7. Запись из Facebook
8. Запись из Instagram
9. Авто-публикация в каталоге DIKIDI Online
10. QR-коды (чаевые/отзыв/запись)

## Клиентский флоу (по профилю компании в каталоге)

- Страница компании: рейтинг (4.9), число оценок, бейдж DIKIDI Awards (ежегодная премия), адрес, часы, телефон (скрыт до клика «Показать»).
- Кнопки связи: WhatsApp, Viber, встроенный чат + большая CTA «Записаться».
- Описание, фото работ, отзывы с датами и **ответами владельца**.
- Фишка конверсии: под отзывом кнопка **«Хочу так же»** — запись сразу на услугу из отзыва.
- Вход клиента: Telegram / VK ID / Яндекс ID / телефон.

## Функционал для бизнеса

- **Электронный журнал**: реалтайм для всех сотрудников, кратность 5 минут, масштаб сетки 5/10/15/30 мин, учёт занятости рабочего места.
- **Клиентская база**: история визитов, статистика по клиенту, разграничение доступа сотрудников.
- **Напоминания**: SMS, push, мессенджеры; запрос подтверждения визита ссылкой; сбор отзывов после визита.
- **Аналитика**: продажи, финансы, возвращаемость, конверсии форм записи.
- **Маркетинг**: рассылки по сегментам (постоянные/«заснувшие»/потерянные), акции на маркетплейсе, премиум-размещение в каталоге, бонусная программа, подарочные сертификаты (онлайн-продажа), приглашение на повторный визит.
- **Деньги**: онлайн-чаевые по QR, приём оплаты, доходы/расходы, расчёт зарплаты с мотивационными схемами, складской учёт.
- **Интеграции**: телефония (аналитика звонков), ККТ Штрих-М и АТОЛ, электронные карты лояльности, SMS-шлюзы, импорт/экспорт записей и графиков.

## Правила бронирования (тонкая настройка — сильная сторона)

- **Предоплата**: фикс или %, по группам клиентов и типам услуг; отдельный шаг оплаты в форме записи (Настройки → Предоплата).
- **Отмена/перенос**: запрет отмены, ограничение по времени (за N часов/дней), штрафы в зависимости от срока.
- **Неявка**: штраф % или фикс; все штрафы суммарно ≤ 100% суммы записи; управление штрафами (списать/отменить).
- **Подтверждение визита**: SMS/мессенджер со ссылкой подтверждения.
- **Предупреждения при записи**: противопоказания, требования консультации.
- **Оферта**: клиент принимает договор при записи.
- **Чёрный список**: ограничение онлайн-записи для конкретных клиентов.
- **Слоты**: фиксированные окна записи + «предлагать другое время после заполнения фиксированного», планирование на месяц+.

## Выводы (для наших проектов)

1. **Крючок — бесплатный базовый тариф без лимита сотрудников**: онлайн-запись им ничего не стоит, монетизация на финансах/маркетинге/SMS/каталоге.
2. **Каталог-маркетплейс = канал привлечения**, не только инструмент: компании получают трафик, DIKIDI — сетевой эффект.
3. **Защита от неявок** (предоплата + штрафы + подтверждение ссылкой) — самый проработанный блок, прямо закрывает главную боль салонов.
4. **Механика «Хочу так же»** под отзывом — образцовая конверсионная связка UGC → запись, стоит перенять.
5. Онлайн-чаевые по QR — «бесплатная» фича, повышающая лояльность мастеров к платформе.
6. Для FrutPed/hab: если делать свою запись — минимум для паритета: слоты с кратностью, напоминания в мессенджеры, предоплата, отзывы с ответами; их слабое место — свой сайт компании остаётся страницей в чужом каталоге (бренд размывается), брендовое приложение дорого.

## Дополнение 2026-08-01 (2): живой доступ в панель владельца

Зашёл в аккаунт Павла (проект «Галерея Красоты», Актобе, тариф Базовый). Панель владельца — `dikidi.ru/ru/owner/<section>/?company=<id>`. Полный список реальных разделов (slug → раздел):

**Записи и расписание:** journal (Журнал записей), schedule (График работы), resources (Ресурсы/рабочие места), services (Услуги), masters (Сотрудники)
**Клиенты:** clients (Клиентская база), retention (Возвращаемость), reviews (Отзывы), chat (Чат с клиентами)
**Онлайн-запись:** propertiesOfOnlineRecord (Настройки онлайн-записи), propertiesOfOnlineRecord_brandApp (Запись в брендовом приложении), integration (Интеграции соцсетей)
**Уведомления:** notifications (Уведомления клиентам), alerts (Оповещения сотрудникам), mailing (Массовые рассылки)
**Деньги:** sales (Продажи), analytics (Аналитика), payment (Приём платежей), acquiring (Эквайринг), biz_cashbox (Кассы), biz_cashflow (Доходы/расходы, ДДС), counterparties (Контрагенты)
**Товары:** products (Товары), products_flow (Движение товара), biz_stock (Склад)
**Зарплата:** payroll, salarySchemes (Схемы), salarySheets (Ведомости), salaryMutualSettlements (Взаиморасчёты)
**Лояльность/маркетинг:** bonuses (Бонусы), seasonTickets (Абонементы), certificates (Сертификаты), tips (Чаевые), shares (Акции), referral_offer (Рефералы), premium (Премиум-размещение), fines (Штрафы)
**Прочее:** ats (Телефония/АТС), permissions (Доступы к проекту), profile (Профиль компании), VerificationDocuments (Документы/верификация), extensions (Модули), support (Поддержка)

Технически вход: POST телефон → `auth.dikidi.ru/ajax/check/auth/` (рендерит форму пароля), POST пароль → `auth.dikidi.ru/ajax/user/auth/` (возвращает token-хэш), затем `dikidi.ru/business?token=<hash>` ставит сессию (cookie `token`). Бот-защита не сработала на обычный curl с браузерным UA.
