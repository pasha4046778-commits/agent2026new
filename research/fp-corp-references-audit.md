## По каждому — что внутри и что берём

**1. SystemKosmetik (Германия).** «Es geht um Ihren Produkterfolg» — полный цикл: разработка → производство → фасовка → упаковка. Объёмы 30–4000 кг, 120 новых продуктов в год, ISO 9001/13485/14001/22716. Технически — Joomla-шаблон, дёшево. **Берём:** модульная подача услуг + блок сертификатов + конкретные цифры мощностей.

**2. Oxygen Development (США).** Категорийная витрина (цветная косметика / скинкер / персональный уход / нутрициональные) + география (6 стран). Elementor-конструктор, тяжёлый. **Берём:** идею карточек категорий продукции; больше ничего.

**3. Kolmar Korea.** Гигант ODM, «No.1 Platform Service Provider». Структура: Company / Business / R&D / ESG / IR. Козырь — карусель 9 исследовательских лабораторий. Для международного посетителя грузится 4+ секунды. **Берём:** R&D-нарратив как ядро идентичности — идеально ложится на нашу историю «хирург + к.ф.-м.н. РАН + патент». Это наш Kolmar-ход в миниатюре.

**4. Herrco (Великобритания).** «Creating Magic. Growing Fast» — дружелюбный тон под стартапы и инди-бренды: MOQ от 5 000 единиц, варки до 4 тонн, склад 75 000 sqft, GMP/ISO. WP+Elementor. **Берём:** тон «мы открыты малым брендам» + прозрачный MOQ — для контрактного производства Эстехим это снимает главный барьер входа («а нас возьмут?»).

**5. Temmentec (Швейцария).** Лучшая ИА из всех: чёткое разделение **Private Label** (Full Service / Ready to Sell / Development) vs **Contract Manufacturing** (производство / фасовка / качество / логистика) + «Alles aus einer Hand». Swiss made, с 1916. Технически — тяжёлый WP с WPML. **Берём:** структуру каталога услуг целиком — это готовый скелет для нашего раздела «Контрактное производство»; «Swiss made» → «Сделано в России по клин. рекомендациям Минздрава».

**6. Fareva (Франция).** Мировой CDMO: 13 000 сотрудников, €2.1 млрд, 42 площадки. Секторы + три формата сотрудничества (subcontracting / customized / turnkey). Самая чистая сборка: 8 скриптов, 57KB. **Берём:** блок ключевых цифр на главной + «три формата сотрудничества» (у Эстехим: своя продукция / контрактное производство / private label).

**7. Cosmax (Корея).** «Science-backed services across the entire beauty pipeline» — ODM/OBM, R&I, глобальные заводы. Vue-кастом, самый современный фронтенд из списка. **Берём:** формулу позиционирования «наука → формула → производство → бренд» и общий уровень визуальной подачи.

## Вывод

- **Технически** референсы клиента не впечатляют: 4 из 7 — WordPress/Joomla с конструкторами, того же класса, что их собственный магазин. Реально хорошо собраны только Fareva (лёгкий энтерпрайз) и Cosmax (Vue).
- **Цепляют** содержанием: Cosmax (наука как бренд), Temmentec (структура услуг), Fareva (цифры/масштаб), Herrco (тон для малых брендов).
- **Наш ход:** делаем кастом на Next.js (как hab-site) — по скорости и свежести обойдём все 7 референсов, при этом дизайн-уровень целим в Cosmax/Fareva. Скелет: герой с производством → цифры → два бренда → «Контрактное производство» по схеме Temmentec (3 формата как у Fareva) → наука/патент (R&D-ход Kolmar) → сертификаты/док-ты → кейсы/отзывы → контакты.
