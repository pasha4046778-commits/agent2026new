2026-09-30 (тред ИИ Креатора, msg 1730-1733): Павел попросил аудит neurover.io и спросил «можем ли собрать аналог для себя».

**Аудит Neurover:** визуальная AI-студия (RU-рынок) — канва с узлами текст→картинка→видео→аудио, чат-режим на телефоне, кредиты. Стек: Laravel + Inertia + Vue 3 + Vite, Caddy→nginx→PHP-FPM. Под капотом — агрегатор чужих generation-API (внутр. роуты price-quotes по провайдерам). Слабости: CSR без SSR (SEO=0, живут на TG-трафике), 290KB HTML + 385KB JS.

**Моя оценка (msg 1733):** технически аналог собрать можем (канва = React Flow, остальное — аккаунты/кредиты/API-интеграции; MVP за несколько недель фоном). НО генералист = венчурная категория (Krea/Recraft/Freepik/Higgsfield, маркетинг-войны) + юнит-экономика: каждая генерация = реальные $ по API, нужны карты для зарубежных API и точный расчёт кредитов.

**Предложение:** нишевый «ИИ-креатор для малого бизнеса КЗ» как модуль движка hab ([[hab-engine]]): владелец кафе/салона жмёт «сделать пост» → карусель IG в стиле бренда / сторис / баннер акции. Прототип конвейера УЖЕ работает: слайды для IG Павла (exports/ig-hab/, HTML-шаблон → chrome-headless → PNG). Продажа пакетом «сайт + ИИ-маркетолог за N ₸/мес».

**УТОЧНЕНИЕ Павла (msg 1734): цель ЛИЧНАЯ, не коммерческая** — генерировать видео для себя без подписок на сторонние сервисы, «своя платформа». Концепт написан: **exports/ii-creator-platform-concept.pdf** (msg 1735-1736). Суть: наш сервер без GPU → открытые модели (Wan 2.2 / LTX-Video / HunyuanVideo, картинки Flux) на serverless-GPU RunPod/Vast с посекундной оплатой (~$0.05-0.2 за клип 5с; 100 клипов/мес ≈ $5-20 против $30 подписки). Архитектура: TG-бот + веб-галерея на хосте, очередь SQLite, GPU поднимается только на генерацию, результаты на нашем диске. План: Этап 0 — ручной тест Wan 2.2 на RunPod по промптам Павла (1-2 дня) → Этап 1 личный генератор (неделя фоном) → Этап 2 цепочки → Этап 3 (опц.) коммерциализация в hab-модуль. ЖДЁМ от Павла: аккаунт RunPod + карта (от $10) + тестовые промпты.
