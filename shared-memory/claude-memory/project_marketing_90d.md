Павел создал тред 1413 «Продвижение проектов» и прислал два 90-дневных маркетинг-плана (автор тот же, что у аудитов; файлы в research/babichnail-marketing-plan-90d.md и research/gudhab-marketing-plan-90d.md, исходники .docx там же).

СУТЬ ПЛАНОВ: fp — фокус на NO BORDER (первый платный тест) + Fruit после проверки мед-обещаний, не делить бюджет на 6 курсов; CAC-пределы по курсам (No Border media CAC ≤3000₸, полный ≤6750₸), стоп-правило 2×CAC без покупки; каналы: своя аудитория → Instagram/Reels KZ → поиск → партнёры (комиссия ~10%); бюджеты 90д: эконом 350К/рабочий 1.22М/рост 2.49М ₸; цель рабочего ~100-110 покупателей. gudhab — два оффера (сайт с приёмом заявок + платформа обучения), автоматизация потом; воронка 40 обращений→24 квал→12 КП→6 оплаченных; цены-гипотезы (стартовый сайт 250-350К, интеграции 450-650К, платформа 0.8-1.2М, поддержка 30-70К/мес); бюджеты: эконом 290К/рабочий 880К; предусловие — GH-01 контакты. Оба: KZ-first, Google Ads RU закрыт, аналитика по серверному purchase, недельные отчёты, точки пересмотра дни 14/30/60/90.

МОЯ ОЦЕНКА (отправлена msg 1423): планы качественные и честные, принять как рамку, НО адаптировать: (1) бюджеты завышены — роли маркетолог/редактор/агент закрываю я, Мария = преподаватель; реальный старт = бесплатные каналы + микро-тест 30К₸ (fp) + 20К₸ (gudhab); (2) план не знает наш актив: база fp ~277 контактов (73 активных + 200+ pending-заявок С ВИДИМЫМ выбранным курсом после моего фикса) + Instagram Марии — канал №1; (3) блокер «5 дней ликвидации» без даты — совпадает с моим Этапом 3.
