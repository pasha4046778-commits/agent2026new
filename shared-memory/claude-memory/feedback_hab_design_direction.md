Pavel approved hab. v0.1 visual direction (2026-05-11) when I invented it from scratch with no prior brand brief. Confirmed: «Отлично, мне нравится».

**What he validated:**
- **Dark-first** as default theme (`oklch(0.14 0.02 250)` background — deep blue-black, NOT pure black)
- **Electric mint accent** (`oklch(0.82 0.20 145)`) as primary CTA color — signals "tech & fresh"
- Warm coral (`oklch(0.70 0.18 25)`) as secondary, used sparingly
- **Bento-grid** layout with asymmetric cells (one wide accent cell colored in primary)
- **Inter + JetBrains Mono** for sans + mono (not Geist — it's Latin-only and we need Cyrillic)
- Lowercase wordmark `hab.` with the dot styled as colored "node"
- Tone: «цифровая мастерская, не агентство» — confident-tech, anti-clichés explicitly stated:
  - No stock-photo «команд в офисе»
  - No 2018-style gradients
  - No «5 шагов работы» blocks
- Grid-line background in hero with radial mask
- Reveal-on-scroll micro-animations + View Transitions API for page nav

**Why:** Pavel asked for «оригинальное в своём фирменном стиле» — i.e. wanted me to commit to a creative direction, not show options. He confirmed without changes, so the whole package landed.

**How to apply:**
- For hab. itself: keep these as the v0 baseline. Don't pivot palette/type without explicit reason.
- For other Pavel projects of similar genre (web studio / portfolio / SaaS landing): this is now a known-good template I can lean on.
- For client-template work (dental, cafe, etc.): each template should have its OWN identity, NOT clone hab. — Pavel explicitly wants different industries to look distinct. Use hab.'s palette only for the hab. site itself.
