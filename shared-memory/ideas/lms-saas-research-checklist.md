# Research checklist для LMS-SaaS

Pavel'у нужно собрать данные ниже **до** коммита в проект (план A-D показал, что идея жизнеспособна, но реализация многолетняя). Пока — отложено, фокус на быстром старте.

## 🔴 КРИТИЧНО — без этого проект не стартует

### 1. Эквайринг для РФ (2-3 систем)
TipTop Pay не принимает российские карты из-за санкций. Нужно:

- **ЮKassa (Сбер):** требования к ИП/ООО, КЭП, комиссия (стандарт ~3.5%), recurring/subscriptions поддержка, срок подключения (обычно 1-2 недели для ИП), мобильный SBP.
- **Робокасса:** требования, комиссия, recurring, срок.
- **СБПэй:** требования, комиссия (часто ниже), для самозанятых упрощённо.
- **Сбер.Pay (Сберэквайринг):** для ООО, более тяжёлый.
- **PayKeeper / Cloudpayments / Tinkoff Pay:** альтернативы.

Что нужно выяснить по каждому:
- Минимальные обороты для подключения.
- Юр. форма (ИП-онлайн, ООО, самозанятый).
- Срок onboarding (1-8 недель типично).
- Recurring subscriptions support — критично для нашей модели.
- API качество, документация.
- Webhook для активации курса после оплаты.
- Reconciliation / отчётность для бухгалтерии.

**Сроки:** изучение 1-2 недели + onboarding 1-2 месяца. Можно начать параллельно с tech-разработкой.

### 2. Юр. оформление
- **Форма:** ИП на УСН 6% / ИП на патент / ООО / самозанятость (не подходит для recurring SaaS).
- **Где регистрировать:** РФ или Казахстан (если Pavel — резидент Казахстана, может быть выгоднее).
- **152-ФЗ ПДн:** обязательная регистрация в Роскомнадзоре как оператор персональных данных, политика обработки на сайте.
- **Оферта:** шаблон + правки от юриста (50-100k ₽ один раз).
- **Договор с tenant'ами:** оферта-присоединение или индивидуальные.
- **Бухгалтер:** ~10-15k ₽/мес on retainer.

**Сроки:** ИП открыть — день. Оферта + 152-ФЗ — 2-4 недели. Для начала Phase 1 не блокирует, но нужно к Phase 2.

## 🟡 ВАЖНО — определяет архитектуру и costs

### 3. Hosting strategy при масштабировании
- **Beget VPS:** текущий тариф, тариф с 4-8 ядер для 50+ tenants. Цены, лимиты.
- **Альтернативы:** Selectel (RU), Reg.ru, Yandex.Cloud, Cloud.ru, MTS Cloud, Timeweb. Сравнить по цене/RAM/CPU/network.
- **Object storage для видео при росте >1TB:**
  - Selectel S3-совместимое (~₽3/GB/мес)
  - Beget S3
  - Mail.ru Cloud
  - Yandex Object Storage
- **CDN:** нужен ли для видео (Selectel CDN, NGENIX, Stormwall — для отдачи в РФ; CloudFront — частично работает в РФ).
- **DDoS-защита:** базовая от Beget vs payed (если бизнес-критично).

**Сроки:** 1 неделя research, 1 неделя миграция при необходимости.

### 4. Маркетинг — бюджет и каналы
- Бюджет старта (рекомендация D-этапа: ~50-100k ₽ на Phase 2).
- Каналы:
  - **Сарафан** — Pavel'ская beauty-сеть. Бесплатно. Главный для первых 5 клиентов.
  - **Контент** — статьи в beauty-сообществах, кейсы FrutPed как референс. Пишем сами.
  - **Контекст:** Я.Директ, VK Реклама. CAC 5-15k ₽, требует тестов.
  - **Influencer:** mid-tier blogger в beauty-нише, post + recommend. 30-100k ₽ за пост.
  - **SEO:** медленно, но дешёвый long-term канал. Нужны 5-10 целевых статей.
- Лендинг продукта (на marketing-сайте `lms.example.com`): UI/UX дизайн, копирайтинг.

**Сроки:** 2-4 недели на материалы + контент-marketing к Phase 2.

### 5. Compliance / данные
- **Хранение ПДн учеников tenant'ов** — ответственность чья? Tenant'а или наша как агрегатора? Юрист уточнит.
- **GDPR-like для не-РФ tenant'ов** — если зарубежные пользователи, нужны политики.
- **Налоговая отчётность для tenant'ов** — продаём подписку им (мы платим налоги с своей выручки), они продают курсы своим ученикам (отдельная отчётность).
- **Эквайринг compliance:** PCI DSS базовый — обычно providers'ы (ЮKassa, Робокасса) берут на себя.

**Сроки:** проконсультироваться с юристом 1-2 встречи (10-30k ₽).

## 🟢 ПОЛЕЗНО — улучшает успех, но не блокирует

### 6. Партнёры
Что можно делегировать (Pavel'у предметно подумать):

- **UI/UX дизайн** — найти дизайнера из beauty-вертикали или AI-savvy. Партнёр на equity или fixed.
- **Маркетинг** — SMM-специалист с опытом в beauty / education niche. Per-project или part-time.
- **Support (после 30+ клиентов)** — part-time customer success на чат/email. ~50-80k ₽/мес.
- **Контент** — копирайтер для landing-pages и блога. Per-piece.
- **Sales** — для корпоратив-tier — отдельный sales person или аутсорс. Не сразу.

**Подход:** Phase 1-2 — Pavel + Paganel/Amber. Phase 3+ — добавляем людей.

### 7. Технические решения, не закрытые в C-этапе
- **Wildcard DNS на Beget:** поддерживается или нет? Если нет — нужен другой DNS-провайдер.
- **Wildcard TLS:** Let's Encrypt через DNS-01 challenge, нужен DNS API token у провайдера.
- **DRM для видео:** наша token-схема — security-by-obscurity. Серьёзный курс с дорогим контентом может требовать Widevine/FairPlay (что есть у Kinescope). Стоит ли встраивать или оставить для optional add-on.
- **Email deliverability:** SES / Mailgun + DKIM/SPF/DMARC настройка.
- **Backup off-site региональный (152-ФЗ требует РФ-сторону для ПДн)**: обязательно если хранить ПДн tenant'ов.

### 8. Финансовый план старта
- Стартовый капитал: для Phase 2 (3 месяца до первой выручки) — оценка 100-200k ₽ (это безналичный, а не «деньги в кармане»).
- Где лежат: Pavel определяет, без обсуждения здесь.
- Burn rate Phase 2: ~30-50k ₽/мес (инфра + tools + minimal marketing tests).

### 9. Quick-customer validation (до Phase 2)
До инвестиций в multi-tenant tech — поговорить с 5-10 потенциальными tenant'ами:
- Хотят ли уйти с Getcourse?
- Сколько готовы платить?
- Что для них критично в LMS?
- Какие из наших фич (видео-защита, авто-конвертация, дизайн) их зацепят?

**Inputs:** Pavel из beauty-сети.
